Core features

Share safely. Compare dates. Keep the record.

Three tools project teams use every week, shown here in the Capture IV project viewer.

  1. 01Secure sharing

    Share the project, not the drive.

    Send a project link and a four-letter access code. Visitors get a read-only view, and your team stays in control of what they see.

    • Project link plus a four-letter access code
    • Read-only viewing for clients and stakeholders
    • Choose which sections visitors can open
    • Set an expiry date or revoke access at any time
  2. 02Compare

    See what changed between flights.

    Put two flight dates side by side and drag the divider to move between them.

    • Pick any two dates with flight routes
    • Drag the divider to reveal more of either side
    • Pan and zoom stay in sync across both views
    • Each side shows the routes flown on that date

    Both sides use the project's site image, with the routes for each date drawn on top. Shown with an illustrative site render.

  3. 03Documentation

    Every file in its project context.

    Reports, plans and logs live with the footage they describe, so nobody has to dig through email for the latest version.

    • Documents stored with the project and dated
    • One-click download for people with access
    • Search across flights and files
    • Documents tab can be shown or hidden for visitors

From the research

Three principles behind the platform.

Drawn from the studies in our field notes. Each links to the summary and the original source.

  1. 01

    A photo is only as useful as its date and place.

    Studies of construction photo documentation point to the same problem: images lose value when nobody can tell where or when they were taken.

    Read the note ↗
  2. 02

    Repeat the same flight to see real change.

    Drone workflows are most useful for progress when capture is repeatable, so one date can be compared with the next.

    Read the note ↗
  3. 03

    Planned and built belong in one view.
