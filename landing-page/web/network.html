Domains to allow

Allow these domains over HTTPS (port 443). Use domain names, not IP addresses: our services run on global networks whose addresses change.

DomainUsed for
www.captureiv.comCompany website
app.captureiv.comCapture IV platform: sign-in, projects, client project viewers
*.r2.cloudflarestorage.comSecure upload and download of project footage, photos and documents (private, time-limited links)
maps.googleapis.com, maps.gstatic.comProject site maps
tile.openstreetmap.org (and a/b/c. subdomains), server.arcgisonline.comStreet and satellite map tiles
photon.komoot.ioAddress search when setting up a project site
unpkg.comMapping library used by the project viewer
accounts.google.comOptional “Continue with Google” sign-in for approved client emails
checkout.stripe.com, billing.stripe.comSecure subscription checkout and billing (account administrators only)
fonts.googleapis.com, fonts.gstatic.comWebsite fonts

Connection security

HTTPS only, TLS 1.2 or newer, HSTS enabled. Plain HTTP is redirected to HTTPS. No other ports or protocols are used.

Suggested web-filter category

www.captureiv.com: Business.
app.captureiv.com: Information Technology / Software-as-a-Service.

About the company

Capture IV is a construction visual-intelligence software company, founded in 2025. Projects are shared through unique, expiring links protected by an access code.
